## 中文介绍

Vnodo 是《我的世界》Vettura 皮卡载具的节点式柔体碰撞物理附属模组。
模组搭载了持久化钣金形变系统、物理挤压场演算，载具的碰撞盒会跟随变形后的车身外壳同步更新。

车辆受到撞击之后，车身产生的凹陷、褶皱会保留下来，不会自动复原。撞击产生的形变会按照物理规律向周边车身扩散，不再是简单的固定静态碰撞盒。撞变形之后的残骸，它的碰撞判定和外观形状保持一致，还原接近 BeamNG 的撞击损毁效果。

## English Introduction

Vnodo is a node-based soft-body crash physics addon for Vettura pickup trucks in Minecraft.

This mod implements persistent panel deformation and physical crush field calculation. The vehicle's collision boxes update synchronously with its deformed shell.

Dents and creases formed after impact will stay permanently instead of resetting. Deformation propagates across the body following physical rules. No static hitboxes anymore. The wreck’s collision behavior matches its crumpled visual shape, bringing crash damage experience similar to BeamNG.

✅ This mod is **open-source**, the source code is public for learning and derivative development.
This is an addon module for Vettura. **Vettura is required.**
